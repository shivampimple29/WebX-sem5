# Question 1

## Problem Statement
> **1. Create a clean, responsive personal profile webpage using HTML5 semantic tags (such as header, section, article and footer) and style it using custom CSS grid/flexbox layouts.**

---

## Solutions Overview
This directory provides two alternative implementations of the solution. You can choose whichever approach best suits your preference or examination requirements:

### 1. `CSS/` (Custom CSS Implementation)
- **Files**:
  - `index.html`: Clean HTML5 markup utilizing semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
  - `style.css`: Clean, minimalistic custom CSS utilizing Flexbox for layout and responsive design.
- **Best for**: Standard web development practicals requiring a dedicated stylesheet.

### 2. `Tailwind/` (Tailwind CSS Implementation)
- **Files**:
  - `index.html`: Identical semantic HTML5 structure styled inline using Tailwind CSS utility classes via CDN.
- **Best for**: Modern utility-first CSS practicals or single-file submission.
